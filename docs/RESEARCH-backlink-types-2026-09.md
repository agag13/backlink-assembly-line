## 1. Infographic submission (11 sites seeded)

**Zinda core**: Infographics Archive (free ~65d / $32 express), Cool
Infographics (free editorial pitch — best link, sirf best assets),
eLearning Infographics (free, education-only — academies ke liye),
Infographic Journal ($25 express), InfographicBee ($14.95), Infographic
Portal ($10 express), + Pinterest/Behance/Flickr (nofollow par audience).
Visualistan = paid £70 "dofollow" — **link-selling footprint, Ankush
approval ke bina nahi.**

**Murda (listicles inhe abhi bhi recommend karti hain — mat bhaago):**
visual.ly, dailyinfographic.com, submitinfographics.com, loveinfographics,
graphs.net.

**Asset spec**: master PNG 800px × 2000–4000px, <1.5MB · footer mein logo +
URL + 3–6 REAL cited sources · derivatives: 735×1102 (Pinterest 2:3),
1200×630 (OG), 1400×1050 (Behance) · **pehle client ke apne blog pe publish
karo embed-code box ke saath** — directories usi canonical ko link karti
hain · descriptions 3 lengths (100+/150-300/300-500w), har site pe UNIQUE.
Realistic ceiling: **~14 placements per asset**.

## 2. PPT / PDF submission (15 sites seeded)

**Ranked**: SlideShare (#1 — deck logged-out readable, verified) → Speaker
Deck (PDF only, 100 lifetime cap) → Scribd (indexing haan, reading gated) →
Calameo (best free limits + **clickable PDF links**) → AnyFlip → FlipHTML5
(team proven — pilot yahan) → Issuu (free ab 5 docs/10pp — flagship only) →
PubHTML5 (FlipHTML5 ka sister — same file dono pe mat daalo) → Yumpu (3
uploads) → SlideServe/PowerShow (volume) → Heyzine/Flipsnack/Zoho.
Simplebooklet = 🔴 6-month expiry = time-bomb links, skip.

**Murda**: edocr (Oct-25 shut), authorSTREAM, SlideBoom.

**Asset spec**: EK master deck per client/topic, do exports — (1) 16:9 PPTX
1920×1080 (SlideShare class), (2) **PDF with embedded clickable hyperlinks**
(flipbook viewers links preserve karte hain; slide-image viewers flatten).
10–16 slides, 30–60 words/slide (transcript indexing ke liye), slide 1 =
keyword title card, last slide = CTA + full URL + NAP. 10-page cut Issuu ke
liye. <20MB, fonts embedded. Title 50–70 chars; desc ki PEHLI line mein full
URL (truncation se bachta hai).

## 3. Video submission (11 sites seeded — Phase 2)

**Core 5**: YouTube (phone-verify karwao), Vimeo (free = 1GB LIFETIME —
sirf polished explainer), Dailymotion (India audience, best non-YT volume),
Rumble, archive.org (permanent + real links — sirf genuinely useful videos).
Odysee/TILvids = incremental. **DTube/BitChute = 🔴 brand-risk — doctors/
academies pe NEVER.** Streamable = 🔴 target hi nahi (90-day auto-delete).

**Murda**: Veoh (Nov-24), Metacafe, Utreon/Playeur, Vidme.

**Minimum viable video (poora ffmpeg-able, koi editor nahi):** 60–120s
slideshow MP4 — 6–10 stills (client photos + stat-cards as 1920×1080 PNG) +
150–170 word script + TTS voiceover (edge-tts, Indian voices:
en-IN-Neerja/Prabhat, hi-IN bhi) + Ken Burns zoompan + xfade + burned-in
captions (mute pe bhi kaam kare). H.264 1080p CRF 21–23 ≈ 40–80MB. Saath
mein 9:16 cut Shorts/Reels ke liye. Ek video → 8–10 platforms, sirf
metadata badalta hai.

## 4. Web 2.0 (14 platforms seeded)

**Top tier (free + indexable + DOFOLLOW + low risk):** Blogger (#1 —
laxest), WordPress.com (spam sweeps: 3+ posts over 2–3 weeks banao),
Google Sites (near-zero risk, mini-site + NAP), Substack (dofollow
verified). **Medium = nofollow + promo blogs bina notice suspend** — sirf
ORM-presence, strict rules. Hashnode/dev.to sirf SaaS/dev clients. Tumblr
outbound links redirect-wrap karta hai (equity zero). Notion free =
NOINDEX. Telegraph India mein Jio-blocked — skip.

**Post spec**: 450–700 words, **har platform pe UNIQUE** (syndication =
biggest footprint), genuinely useful (doctor = ek real patient question),
exactly 1 in-body brand link (branded anchor, money-keyword kabhi nahi) +
optional 1 bio link, 1 image 1200×675, India-specific detail (city, INR),
humanizer pass. Title = question/how-to, 50–60 chars.

## Cross-type ground truth

- In sab platforms pe description/profile links **nofollow** hain (web2.0
  in-post + Substack + Blogger/WP/Sites/Hashnode dofollow exceptions).
  Value 3 channels se aati hai: (1) platform page khud Google mein rank
  hota hai, (2) flipbook/PDF ke andar clickable links referral dete hain,
  (3) brand-SERP real estate (ORM ke liye gold).
- Har asset pehle client ki apni site pe canonical ke saath, phir
  distribution.
- Pehla asset per client = Ankush approval, uske baad batch.
