# Content pack templates

One pack = everything a human pastes for ONE site × ONE client. Field names
below match what listing/classified/profile sites actually ask for.

## Business listing / local citation pack

```
=== PACK: <root domain> × <Client> ===
Submission link : <col H link, else the site's add-listing page, else root domain>
Est. time       : 30–60 sec after login

Business Name   : <registry project name, cleaned for public display>
Category        : <best pick> (alternates: <2–3 more, in likely site vocabulary>)
Short Descr.    : <≤160 chars, plain, keyword once, no phone numbers>
Long Descr.     : <120–180 words, unique to this site — see uniqueness rules>
Address         : <registry Address, verbatim>
Phone           : <public phone from client website>
Email (public)  : <public contact email from client website — NEVER an account credential>
Website         : <registry website url, https, trailing slash consistent>
Hours           : <from client website if shown>
Map / GMB       : <registry map url>
Keywords/Tags   : <registry keyword + 2–4 natural variants>
Anchor plan     : brand name for the link text where the site allows anchors;
                  naked URL otherwise; exact keyword anchor at most 1 in 5 sites
Images          : <logo; 1 real photo (classroom/clinic/office); square ≥512px;
                  filename = business-name.jpg>
Site notes      : <quirks from the inventory example URL: login-first?, category
                  list style, draft-approval delay, which fields are required>
```

## Classified ad pack (adds to the above)

- Ad Title: <business name + city + one benefit, ≤70 chars>
- Ad body: reuse long description, prepend one-line offer/CTA
- City/Location pickers: city from registry address
- Price field: "Contact for details" unless the client publishes prices

## Profile / social bookmark pack (content backlinks sheet)

- Display name: brand or author name (consistent across sites)
- Bio (≤160 chars): short description variant
- Profile links: target article URL (col B of Daily work report) + site URL
- Bookmark title: target article's real title; description: 1–2 sentences on
  the article (not the business)

## Description uniqueness rules

Every site gets a DIFFERENT short + long description. Rotate along these axes
so N variants stay natural, not spun-text:

1. Lead angle: what-we-do / who-it's-for / outcome / location-first / program-first
2. Sentence order and rhythm (don't reuse an opening clause twice)
3. Which 2–3 concrete facts appear (courses, hours, placement support, tagline)
4. Keyword placement: title-adjacent in some, mid-text in others; NEVER
   keyword-stuff — once or twice per description max

Facts pool = registry row + client website only. If a fact isn't in either,
it doesn't exist. No superlatives that imply rankings ("best", "#1") unless
the client's own site uses them, and no invented reviews/testimonials ever.
